# CodeAlpha Task 4 - Weather Dashboard

## Project Description

A real-time weather dashboard developed using HTML, CSS, and JavaScript.

## Features

- Search weather by city name
- Fetch real-time weather data
- Display temperature
- Display humidity
- Display wind speed
- Error handling
- Asynchronous JavaScript using async/await
- REST API integration

## Technologies Used

- HTML5
- CSS3
- JavaScript
- REST API
- Fetch API
- Open-Meteo API

## How to Run

1. Download or clone the project.
2. Open the project in VS Code.
3. Open index.html using Live Server.
4. Enter a city name.
5. Click Search.
